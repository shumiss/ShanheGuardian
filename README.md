# 山河守护

面向全国复杂地形旅游的 AI 伴游、安全预警与协同处置平台。贵州保留为首个完整样板区域；其他地区通过高德景区动态检索、全国城市天气和统一安全规则生成区域化路线。

当前版本：`2026.08-national-p1`

## 已完成能力

- 自然语言需求、游客类型、旅行偏好、强度、天气、出发日期和 1 至 10 天行程生成
- 支持输入任意省、市或景区片区，全国常用目的地可快速切换
- 贵州保留 2,017 条本地 POI 样板；其他地区使用高德 Web 服务动态检索，不冒充全国离线数据集
- 全国实时候选使用高德 POI 2.0，读取可用的营业时间、评分、电话和实景图字段
- 最近邻、约束修复与 2-opt 共同完成路线排序，并公开优化前后距离
- 输出精确到分钟的到达、等待、游览和离开时间；缺失营业时间时明确标记规则估算
- 按景点坐标实时检索附近医院、派出所和游客中心，写入风险证据
- 降雨情景推演生成独立路线快照，比较风险和替换点位，未经确认不覆盖主计划
- 路线、风险解释、应急覆盖和数据血缘共用同一 `planId` 决策快照
- 安全优先、均衡体验、探索优先三种多目标策略会生成不同路线，并返回目标权重、优化得分和策略对比
- 每次规划返回候选召回、天气调用、约束求解、道路校准和摘要生成的真实执行轨迹与耗时
- 指定目的地、单段距离、每日负荷和实景图覆盖形成可复核的硬约束检查
- 地图按“当日/全程”联动点位、线路和风险摘要
- 高德驾车路径适配，成功时返回道路折线、公里数和车程；失败时明确标记为点位关系估算
- 全国城市高德天气适配；未来日期不会把今日实况冒充预报
- 客流授权接口适配；未授权时只显示客流压力估算，不显示虚构实时人数
- 安全事件、责任资源、动作、备注和审计记录后端持久化
- MindIE/vLLM Ascend 兼容推理请求、响应解析、超时、状态记录和本地降级
- 游客端与管理端双窗口路线实时同步

## 本地运行

要求 Node.js 20 或更高版本。

```powershell
cd backend
npm install
npm start
```

后端地址：`http://127.0.0.1:8093`

```powershell
cd frontend
npm install
npm run dev
```

游客端：`http://127.0.0.1:5173`

管理端：`http://127.0.0.1:5173/?mode=demo`

## 环境变量

参考 `backend/.env.example`，不要提交真实密钥。

- `AMAP_WEB_SERVICE_KEY`：高德天气、静态地图和驾车路径规划
- `AMAP_WEB_SERVICE_SECRET`：启用高德数字签名时填写
- `CROWD_FLOW_API_URL`、`CROWD_FLOW_API_TOKEN`：景区授权客流
- `ASCEND_INFERENCE_URL`：MindIE/vLLM 的 OpenAI 兼容 `chat/completions` 地址
- `ASCEND_API_KEY`、`ASCEND_MODEL`、`ASCEND_TIMEOUT_MS`：昇腾推理配置
- `INCIDENT_STORE_PATH`：安全事件持久化文件位置

## 自动测试

```powershell
cd backend
npm test

cd ..\frontend
npm run build
```

后端测试覆盖基础接口、路线与解释一致性、1 至 10 天行程、指定景区可达性、敏感文件防泄露、安全事件持久化和真实昇腾 HTTP 适配器契约。

浏览器回归脚本位于 `frontend/tests/e2e-smoke.mjs`，覆盖日期联动、地图点位一致性、双窗口同步、事件刷新恢复和 390px 移动端布局。运行前需要安装 Playwright，或通过 `PLAYWRIGHT_MODULE_URL` 指向可用模块。

路线优化基准：

```powershell
cd backend
npm run benchmark:route
```

2026-08-27 本地样板基准包含 12 类场景、3 种策略、36 次规划：硬约束通过率 100%、分钟级日程可执行率 100%、策略路线差异率 100%、完整工具轨迹率 100%，P50 约 100ms、P95 约 250ms。结果位于 `work/route-benchmark-latest.json`。该结果用于本地回归与方案对比，不代表全国生产环境性能。

开源参考与融合边界见 `docs/OPEN_SOURCE_REFERENCES.md`。

## 数据口径

- 高德 POI 是风景名胜检索结果，不等同于文旅主管部门 A 级景区正式名录。
- 贵州以外区域当前使用实时检索候选池；尚未声称完成全国景区离线数据建设。
- 3 条节假日公开样本用于规则校准，不代表实时票务或实时客流。
- 非核心点位的坡度、服务覆盖和部分风险特征属于规则估算，界面和接口会保留数据来源说明。
- 贵州省语料（数据集）中心目前接入的是公开目录元数据；在正式数据授权前，不声称目录内容已进入模型训练。
- 未完成远程推理验证时，系统显示“本地决策服务”或“适配器已就绪”，不会显示“远程昇腾推理”。

## 决赛前外部依赖

仍需主办方、景区或合作方提供至少两项正式公共数据内容及授权证明、景区票务或闸机客流、应急服务点正式名录，以及可访问的昇腾推理服务。上述外部依赖不会用模拟数据冒充。
